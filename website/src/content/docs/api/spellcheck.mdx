## TypoDetector

Main spell checking and correction class. Detects typos using Akshara Trigram scoring + BiGRU sequence labeling and corrects them using a hybrid retrieval-generative pipeline.

### Code Examples

#### Import and Load
```python
from sinlib import TypoDetector

detector = TypoDetector.from_pretrained()
```

#### Sentence Correction (Call)
```python
# Correct a full sentence
corrected = detector("ගුරුවරයා අපට උගන්වය්")
# 'ගුරුවරයා අපට උගන්වයි'

corrected = detector("සිංහල බාෂාව ලස්සනයි")
# 'සිංහල භාෂාව ලස්සනයි'
```

#### Context-Aware Suggestions
```python
# Without context
detector.suggest_correction("පසලට")
# ['පාසලට', 'පාසැලට', 'පවුලට']

# With surrounding context
detector.suggest_correction(
    "ලසන",
    prev_word="ලංකාව",
    next_word="රටක්"
)
# ['ලස්සන', 'ලේඛන', ...]
```

#### Detection Only
```python
detector.is_word_suspicious("සිංහල")
# False — valid word

detector.is_word_suspicious("සින්හල")
# True — likely typo
```

#### Check Probabilities
```python
prob = detector.word_ngram_probability("සිංහල")
# ~3.2e-05  (higher is more common)
```

#### Neural Correction (CharBERT, optional)
```python
# pip install "sinlib[charbert]"
detector = TypoDetector(neural_backend="hybrid")

detector("මම ගෙදර යන්ඩ ඕනේ")
# 'මම ගෙදර යන්න ඕනේ'  (dialectal morphology)

detector("මම gedara යන්න ඕනේ")
# 'මම ගෙදර යන්න ඕනේ'  (Singlish code-mixing)

detector("ක්රීඩාව")
# 'ක්‍රීඩාව'  (ZWJ-damaged ligature)

# Point at a local checkpoint instead of the Hub
detector = TypoDetector(
    neural_backend="seq2seq",
    backend_model="/path/to/checkpoint",
)
```
