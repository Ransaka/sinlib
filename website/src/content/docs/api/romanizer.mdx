### Code Examples

#### Import and Load
```python
from sinlib import Romanizer

romanizer = Romanizer()
```

#### Single Text Romanization
```python
romanized = romanizer("මම ගෙදර ගියා")
# 'mama gedara giya'
```

#### Batch Romanization
```python
res = romanizer([
    "මම සිංහල ඉගෙන ගන්නවා",
    "ලංකාව ලස්සන රටක්"
])
# ['mama sinhala igena gannawa',
#  'lankawa lassana ratak']
```

#### Non-Sinhala Content Preservation
```python
romanizer("සිංහල 123 english!")
# 'sinhala 123 english!'
```
